### 简介：
本项目的本体为一个应用程序，其通过解析微信本地聊天记录写入内存的密钥的方式解密并导出现有的聊天记录；
支持导出`文字消息`、`部分图片与视频`^需要本地有存档^；
如果没有存档则会显示为`视频 wide*high time`、`图片 wide*high`；
可以显示微信本身内置的表情但自己与他人的表情无法导出，会显示为`🙂表情`；
支持解析非 微信专有域^比如视频号^ 的链接为`可点击链接卡片`；
会自动在导出时将 b23.tv 短链跟随跳转解析成 https://www.bilibili.com/video/BV… 的形式。

#### 支持：
`微信聊天记录导出器.exe`使用Python编写，理论支持Win7+
`WinUI-应用\微信聊天记录导出器-WinUI.exe`使用Win UI3作为壳，底层与*微信聊天记录导出器.exe*相同，理论支持Win10+~（似乎存在BUG导致无法进行爬取）~

### 使用方式：
#### 一、导出聊天记录
1. 下载 *仓库源码* ~不包含WinUI3版本~ 或 *Release* 中的包
2. 解压缩到任意位置
3. 开启电脑上的微信主程序并登录
4. 打开`微信聊天记录导出器.exe`或`WinUI-应用\微信聊天记录导出器-WinUI.exe`
5. 在软件界面选择账号、输出目录后点击`导出选中`
6. 若选择的保存位置有之前导出的聊天记录，则会弹出询问`覆盖`或`补充`
```language txt
模式解释：
“覆盖模式”会直接删除原有的所有文件，请谨慎选择
“补充模式”会在保留原有文件的情况下在文件末尾补充这次导出时相较上次新增的消息
```
7. 等待程序从内存中获取解密密钥后解密聊天记录
`大部分图片由于本地没有缓存可能无法保存和解密，建议先点开 2~3 张聊天图片，
这样图片密钥才会进内存。`
8. 当弹出提示`导出成功`后便可关闭程序
9. 如果存在
#### 二、阅读聊天记录
1. 打开你在程序中选择的保存位置文件夹
2. 打开其中名称格式为`微信记录_wxid_xxxxxxxxxxxxxx_xxxx`的文件夹
3. 打开`聊天记录.html`即可查看聊天记录
4. 消息按照群和对话分组，逻辑与微信原版基本相同
5. `视频 wide*high time`、`图片 wide*high`、`🙂表情`的内容可以点击后在新标签页查看，并且支持自行匹配文件
```language txt
文件匹配说明：
首次匹配需要先选择当前界面所在的文件夹（授权修改以复制文件）
随后选择要替换/显示为当前位置消息的文件即可，
网站会复制一份文件到存储的位置用于显示。
```
